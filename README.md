# Rental Visual BA

Sistema de alquiler y control de equipamiento audiovisual.
Prácticas Pre Profesionales 2026 — Universidad Nacional de Lanús (Lic. en Sistemas).

Caso de estudio: gestión integral de un negocio de alquiler temporario de bienes audiovisuales de alto valor patrimonial ("Rental Visual BA"), con disponibilidad estricta por rangos de fechas (sin doble reserva), control de ciclos de check-out/check-in, supervisión del estado técnico/operativo de los equipos y gestión de garantías, cobranzas y penalidades por mora.

## Stack tecnológico
- Base de datos: SQLite
- Backend: Node.js + Express (REST API)
- Frontend: React (responsive, celular y mostrador)
